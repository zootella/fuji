# Video spike

The floor is built and released on all three platforms: one media library from one recipe, four player commands and a panel that are the same code everywhere, and a native rectangle per platform that a video draws in. What the floor is and why it is shaped that way lives in the code's essays, `CLAUDE.md`, the README and the Free Software article. What is still open in this sprint is on the picture side beside it, below.

## The tables and the native image pathway (nicknamed "NativeTable": scoped soon in this sprint)

The native image pathway, ImageIO on the Mac and WIC on Windows, draws for the sheet's thumbnails alone today, and that is a first draft's simplification rather than a design: the same libraries decode a picture at any size asked, orientation and colors applied, so a table can show a picture through them by asking for its own size, painting the raster onto a canvas once, and zooming with the CSS it already zooms an img with. TIFF on Windows is the example the lists already hold. WIC reads it, so `imageNative` names Windows; Chromium has no TIFF decoder, so `imageWeb` does not; and today that means a thumbnail on the sheet and an error card on the table. The lists stay as they are, since they say what each pathway can do, and the table is what catches up: a Rust command that asks the operating system for the picture at its own size, through the same ceiling check the thumbnail command holds, a card that can hold a canvas beside the store's img, and the table taking the web pathway where its list names the platform and the native one where only that list does. The same route serves .tga and .psd and the camera raws on the Mac, where ImageIO alone reads them.

## Transparency through both image roads (nicknamed "ClearTest": smoke test in this sprint)

The native road keeps a picture's alpha channel: the thumbnailer hands back straight-alpha pixels on the Mac and on Windows, the sheet's canvas keeps them, and the ground shows through, so a transparent PNG needs no background color sent to rust and stays on both roads, while GIF and SVG stay on the engine for animation and vectors rather than for transparency. To see it: a transparent PNG, a transparent GIF and an SVG with open space, on the contact sheet and on the Diamond Table, in light and in dark, where the ground should show through each in the theme's own color and never as white, black or a checkerboard. The PNG tile is the one that takes the native road on the Mac and Windows, and the other two are the engine's own.
