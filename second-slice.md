# Second slice (nicknamed SecondScoop)

## After the second slice

- **RectanglePixels.** Width and height are counts of the pixels a file stores, in every format. Open is what the answer adds for pixels that are not square: an aspect ratio, or a second width and height at the shape it shows at. The MP4 reader reports the track header's size, which is the shown size, and the stored count is in the sample description, deeper in the track.
- **BookDimensions.** An MP4 track counts as the picture when its header has a size, so a subtitle or chapter track can lend an audiobook a width and height. The track's handler box says `vide` for video, about 10 lines by estimate.
- **FalsePositive.** A few signature rows can fire on ordinary files: `MAC ` names a text file that opens with it APE audio, `MZ` names any file that opens with it an executable, `FWS` and `CWS` are three letters, and AC-3 and gzip are two bytes each. A caller sees such a file's bytes disagree with its extension, but the scout skips its text verdict whenever a signature matches.
