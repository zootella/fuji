# Theme

**Whether fuji keeps Zed's lightness.** The grays fuji names for a job take their lightness from Zed's One Light and One Dark, apart from those a platform gives, and the user is no longer certain of Zed. If another palette is liked better, GNOME's for instance, fuji might switch to it, keeping the values it has and perhaps mapping them onto the numbered grays.

**Whether the other dark grays follow the face down.** Each was set for its distance from Zed's dark ground, `#2c2c2c` with its tint out, and the face follows the file managers instead.
